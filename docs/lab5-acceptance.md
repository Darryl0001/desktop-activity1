# Lab 5 acceptance and traceability

**Execution date** November 27, 2026, Manila time. **Application clock** 2026-11-10 in Asia/Manila for every test.

The run used .NET SDK 10.0.400, a disposable PostgreSQL 18.6 cluster, and an independently started ASP.NET Core process on loopback. The runner applied both existing migrations and reset the supplied S1–S4 and E1–E7 fixture before each case and the independent T05 subcases. Requests use IDs resolved from the API. Mutation evidence records a fresh PostgreSQL read before and after the request.

The first acceptance run passed T01–T08. Review of the UI captures found that an unreachable API still exposed the empty search prompt on first load. The desktop now shows empty results only after a successful read, and the failure test asserts that behavior. The retest also exercised loss of a write response after commit. See the [first run summary](evidence/lab5/first-run-results.json), [final run summary](evidence/lab5/run-results.json), and [Lab 4 regression output](evidence/lab5/lab4-regression-run.txt) for the 21 passing regression checks.
